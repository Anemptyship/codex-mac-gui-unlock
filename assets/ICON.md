# Application icon

Original AI-generated artwork created with the built-in image generation tool, then resized with Apple's sips solely for macOS icon packaging. This is artwork, not a desktop screenshot. No references to OpenAI branding or third-party assets are used. The application build creates a full-resolution ICNS icon using iconutil and binds it through CFBundleIconFile.

Final edit prompt: Remove both eyes and the entire mouth completely, replacing them with uninterrupted smooth satin ceramic surface. Absolutely no face, eyes, nose, mouth, eyebrows, or anthropomorphic features. Preserve the pastel rounded-square tile, open shackle, padlock silhouette, soft 3D materials, lighting, composition and transparent exterior. Keep the padlock body completely plain: no text, symbols, keyhole or logos.

The generated source was 1254 by 1254 pixels with alpha; the committed app master is 1024 by 1024 with alpha. assets/manifest.json records its exact SHA-256. The source scanner permits only that reviewed image and still rejects arbitrary screenshots and private artifacts.
